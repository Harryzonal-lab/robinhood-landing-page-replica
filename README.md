# Robinhood homepage recreation

React + Vite + Tailwind CSS recreation with the original desktop hero video URL supplied by the user. Includes a scrolling landing page: hero, trading tools, crypto, portfolio management, protection, investor education, and footer.

## Run locally

```bash
npm install
npm run dev
```

The hero video and remote assets require an internet connection. This is an educational recreation, not an official Robinhood product.
